# 🌍 SDGs 17 올림픽 대륙별 모둠 매칭 (1~6모둠 자동 추첨)

이름 입력 없이 **1모둠부터 6모둠까지의 숫자**가 무작위로 각 대륙에 날아가 꽂히는 모둠 추첨 웹앱입니다.

---

## 🛠️ 주요 기능
1. **이름 입력창 제거 & 즉시 추첨**
   - 별도로 명단을 적을 필요 없이 우측 하단의 [추첨 시작!] 버튼만 누르면 바로 매칭이 시작됩니다.
2. **모둠 번호 깃발 애니메이션**
   - 1부터 6까지의 숫자가 적힌 깃발이 화면 밖에서 날아와 각 대륙 구역 정중앙에 꽂힙니다.
3. **가시성 높은 결과 뱃지**
   - 깃발이 꽂히면 대륙 테마 색상과 동일한 두꺼운 폰트의 **'O모둠'** 뱃지가 나타나 멀리서도 배정 결과를 쉽게 확인할 수 있습니다.

---

## 🚀 사용 방법 (Windows/Mac 공통)
1. 컴퓨터 바탕화면에 새 폴더를 만듭니다.
2. 다운로드하신 **`index.html`** 파일과 함께, 배경 지도로 사용할 원본 이미지 파일을 **`image_34ec36.png`**라는 이름으로 같은 폴더 안에 저장합니다.
3. **`index.html`** 파일을 마우스로 더블클릭하면 인터넷 창이 열리면서 바로 실행됩니다!
